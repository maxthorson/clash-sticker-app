# Clash Sticker App

An iMessage sticker app workspace for Clash-themed stickers and custom sticker
pack experiments.

This folder contains the `BM` sticker pack project and a customized
`boohoohoo` Messages extension based on Apple's sticker app sample code. The
Apple sample license is preserved in `boohoohoo/LICENSE.txt`.
